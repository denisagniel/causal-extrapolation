## Note — Candidate related-work citation for Path 3

**Paper:** Burman, Gamalo, Ghosal, Kundu (2026). "Transporting Randomized Trial Effects to
Real-World Populations via Riesz-Calibrated Optimal Transport." arXiv:2608.23453 [stat.ME].
Submitted 24 Aug 2026.

**Relevance:** Directly on-topic for Path 3 ("Identification via covariate transport,"
`main.tex` ~L367–421). RICOT transports RCT effects to a target population via
Riesz-calibrated optimal transport, is doubly robust, attains the semiparametric efficiency
bound, and estimates variance directly from the influence function (no resampling) — the
same machinery Path 3 uses for the density-ratio weight $w(\bx)$. RICOT is built specifically
to handle **weak covariate overlap**, which is exactly the failure mode flagged in the paper
(L359: "transport is not credible and the estimator's variance degrades") and matches the
application's overlap-limited effective sample sizes (n_eff 8–36/43, per 2026-07-10 notes).

**Two uses identified:**
1. **Citation** — slot into related-work Prompt 7 (external validity/transportability) in
   `development-docs/citation-gaps-and-outline.md`, alongside Pearl/Bareinboim, Egami &
   Hartman.
2. **Possible methodological angle** — their calibrated-OT estimator for the density ratio
   under weak overlap could be worth comparing against Path 3's current $w(\bx)$ estimator,
   given the application already runs overlap-limited. Not adopted; flagged only.

**Status:** Not yet added to `.bib` or cited in text. Deferred — no action taken this
session beyond identifying and logging it.
