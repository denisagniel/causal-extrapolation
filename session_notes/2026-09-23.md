Ran `sim_section4b_real_firststage.R` locally at 1000 reps
(`n_replicates <- 1000L`; ~2.9 min wall time, well within budget — no memory
issue). **First run surfaced a real bug**: coverage 95% = 22.7% (target
95%), coverage 90% = 16.0% (target 90%), despite variance ratio ≈ 1.04 (i.e.
the *variance* was correctly calibrated — this was a *bias* problem, not a
variance problem). Diagnosed via a 100-rep raw-estimate check: mean estimate
0.305 vs true FATT 0.427, bias ≈ −0.122 ≈ one unit of the average slope
(mean(β_g) ≈ 0.10) — a strong signal of an off-by-one indexing error.

Root-caused two independent bugs in the real-first-stage pipeline (both in
simulation glue code, not package internals):

1. **Off-by-one in the extrapolation target.** `generate_panel_data()`
   relabels cohorts/calendar time as `g_did = g_orig + 1`, `t_did = t_orig +
   1` (to guarantee `did::att_gt()` sees a pre-period for every cohort).
   `as_gt_object()`/`gt_object_from_att_gt()` (`R/from_did.R`) copies
   `att_gt()`'s `$group`/`$t` verbatim — no un-shifting — so the resulting
   `gt_object` lives in did-space calendar coordinates. But
   `sim_section4b_real_firststage.R` called
   `extrapolate_ATT(..., future_value = future_time, time_scale = "calendar")`
   with `future_time` in *original*-space. That targets the last *observed*
   did-space period instead of one period ahead. Fixed by adding
   `future_time_did <- future_time + 1L` and using it in the
   `extrapolate_ATT()` call. Verified: this alone took coverage from
   22.7%/16.0% to 86.0%/77.0% at 100 reps — large improvement, but still ~9pp
   short of nominal (real, not noise, at n=100).

2. **Pre-treatment placebo cells leaking into the linear fit.**
   `did::att_gt()` reports ATT(g,t) for every (g,t) pair it can identify,
   including pre-treatment placebo cells (t < g, event time k < 0, true
   effect ≈ 0 by design) used for parallel-trends diagnostics — confirmed by
   inspecting `gt$data` directly (k range −2..4, three k<0 rows present).
   `hg_linear()`/`extrapolate_ATT()` fit one OLS line per group across
   *whatever* rows they're given; pooling near-zero pre-treatment estimates
   with the increasing post-treatment cells flattens the fitted slope and
   biases the extrapolated FATT downward. The synthetic first stage
   (`add_noise_and_eif()`, sections 1–8) never exposed this because
   `make_theta_gt()`'s grid is already post-treatment-only — this only shows
   up once a real first-stage estimator that reports placebo cells enters
   the pipeline. Fixed in `add_did_eif()` (`sims/scripts/dgp_helpers.R`):
   filter `att$group`/`att$t`/`att$att`/`att$se`/`att$inffunc` to `t >= g`
   before calling `as_gt_object()`. (`att` is a plain S3 list, `$inffunc` a
   `dgCMatrix` — both filter cleanly with logical/column indexing.)

Verified the combined fix at 300 reps: coverage 95.3%/91.3% (targets
95%/90%) — within noise. Final 1000-rep run: **coverage 95.2%/90.8%,
variance ratio 1.023** — nominal. `sims/results/section4b_real_firststage.rds`
now holds this validated 1000-rep result.

Propagated fix (2) automatically to the O2 harness since `sims/section4b/R/run_one.R`
sources the same `dgp_helpers.R`. Fix (1) had to be duplicated: added
`S4B_FUTURE_TIME_DID <- S4B_FUTURE_TIME + 1L` in `sims/section4b/R/dgp.R` and
updated `run_one.R`'s `extrapolate_ATT()` call to use it. Confirmed
`sims/section7est/` is unaffected by either bug — it uses
`add_noise_and_eif()` (no `did::att_gt()`, no cohort relabeling) for
path1/path2 and a separate unconfoundedness DGP for path3, so no did-space
shift or placebo-cell issue applies there.

Added the section4b results table to the paper (table only, no narrative
text, per user instruction). Extended `sims/scripts/write_paper_tables.R`
with a Section 4b block (mirrors the existing Section 4 table) writing
`inst/paper/sim_tables/section4b.tex` from the validated 1000-rep
`section4b_real_firststage.rds`, and added `\input{sim_tables/section4b}`

prose). Compiled clean: 0 overfull hboxes; renders as Table 5, page 24
(EIF-based variance and Wald coverage, real `did::att_gt()` first stage;
variance ratio 1.02, 95%/90% coverage 95.20%/90.80%, 1000 replicates).
